# English Study Fast — Ruta C1 basada en evidencia

Plan completo y científicamente fundamentado para llevar tu inglés a **nivel C1 (CEFR)** aplicando *Ultralearning* (Scott Young), *Deep Work* (Cal Newport) y *Práctica Deliberada* (K. Anders Ericsson), junto con los principios de *Second Language Acquisition* (Krashen, Swain, Nation, Long, Bjork).

## Contenido del repo

| Archivo | Qué encontrarás |
|---|---|
| `docs/01_research.md` | Investigación: qué dice la ciencia sobre aprender inglés hasta C1. |
| `docs/02_materials.md` | Bibliografía, apps, podcasts y herramientas (consíguelas antes de empezar). |
| `docs/03_daily_plan.md` | Ruta diaria de 60–90 min, plan semanal y fases mensuales. |
| `docs/04_tracking.md` | Sistema de tracking semanal (métricas, plantillas, checkpoints). |
| `tracking/weekly_log_template.md` | Plantilla para copiar cada semana. |
| `tracking/monthly_checkpoint_template.md` | Plantilla de autoevaluación mensual. |

## Cómo usar este repo

1. Lee `docs/01_research.md` para entender **por qué** cada método del plan está ahí (30–40 min).
2. Lee `docs/02_materials.md` y **consigue los materiales antes del Día 1** (libros, cuenta Anki, ChatGPT/Claude, 1 tutor en iTalki o Preply).
3. Sigue `docs/03_daily_plan.md` como guía diaria.
4. Cada domingo rellena `tracking/weekly_log_template.md` (15 min).
5. Cada 4 semanas haz el *checkpoint* en `tracking/monthly_checkpoint_template.md` (45 min) y ajusta la ruta.

Objetivo realista: **B2 sólido → C1 en 6–9 meses** con 60–90 min/día constantes (≈ 200–300 h de estudio dirigido + input pasivo adicional). Cambridge English estima ~200 h guiadas para saltar de B2 a C1.
