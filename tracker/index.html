Rutina de 120 min (4 hilos × 30 min)

  1. Lenguaje: Anki 20′ + gramática o pronunciación 10′.
  2. Input: lectura extensiva 15′ + escucha extensiva 15′.
  3. Output: conversación, o texto con feedback + reescritura (30′).
  4. Fluidez: lectura rápida fácil 10′ + audio conocido 5′ + 4/3/2 o escritura cronometrada 15′.
Versión mínima de 60 min: 15′ por hilo. La escucha en tiempo muerto se registra como pasiva: suma exposición, pero no cuenta para la meta.

Exportar / importar

Los datos se guardan solo en este navegador. Exporta con regularidad y guarda los CSV en tracker/data/ del repo: es el mismo formato que usa python tracker/progress.py.

Al importar se añaden solo las filas que aún no tienes (no se duplican, y se conservan las sesiones idénticas legítimas). Acepta CSV con coma o punto y coma (Excel en español) y coma decimal.
